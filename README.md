# Happy Birthday, Bebe 💙

A handmade-feeling birthday website: envelope surprise → greeting → memory lane →
a letter → make a wish → a final gift.

## Make it yours
Everything personal is in **`config.js`**:
- **Photos:** put files in `photos/` and write their names, e.g. `{ src: "photos/1.jpg", caption: "…" }`.
- **Text:** every heading, message, button and the letter.
- **Music:** off until the Play button is pressed. Add a YouTube link or `music/song.mp3`,
  or leave both empty for the built-in music-box "Happy Birthday".
- **Knight kitten clip:** `gift.knight` (set `src: ""` to hide it).

Open a specific page while editing: `index.html#s1` … `index.html#s6`.

## Put it online (GitHub Pages)
Publish this folder with GitHub Desktop as a **public** repo, then
Settings → Pages → Deploy from a branch → `main` / `(root)`.
